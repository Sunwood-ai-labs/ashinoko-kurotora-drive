# 検証記録と既知の制約

## 確認済み

- GitHub Pagesへ公開し、公開URLへ認証なしで到達
- 配布ファイルのSHA-256が公開commitの内容と一致することをCIで検査
- JavaScript構文、GLBヘッダ・長さ、内部パス・開発用URLの混入を検査
- コース契約26検査、10,016点の経路、209,834件の配置、車体から独立したパックの再配置・export後の再検査
- 読み込み中の描画context喪失を4段階へ注入した回帰テストと、初期化失敗時の案内・再読み込み動作テスト
- コース補間・高さ・勾配・曲率が全周で有限値
- 無入力で停止、加速、制動、左右操舵、完走判定
- 自動走行の全周完走。v4基準データでは約25.03 kmを模擬約23分41秒、路肩接触0回
- 制作時の別検査でGLB復号、geometry結合、車体寸法、圧縮前後のbuffer一致を確認

最後の項目は現在の配布CIが自動再実行する範囲と同じではありません。CIが検査する内容は実際のテストスクリプトを参照してください。

## ブラウザ検証の限界

2026-10-04の公開確認に使ったクラウドChromiumはGPU/WebGLが無効でした。公開HTML/CSS/JavaScriptは読み込めますが、`WebGLRenderer` のcontext生成前に失敗し、ゲーム中の3D画面には到達していません。

そのため、以下は**未検証**です。

- 実ゲーム画面の材質・影・植生・全周の見た目
- 実ブラウザのキーボード・マルチタッチ操作の全経路
- デスクトップ・スマートフォン別のFPS、ロード時間、メモリ量
- 自動走行を実時間で最後まで表示した場合の安定性

WebGLを使えない場合の案内UIは用意しています。環境の保護機能を無効にして検証する方法は案内しません。

## 既知の制約

- アーケード用の近似物理です。タイヤ・サスペンション・実車特性の厳密なシミュレーションではありません
- 道路形状や風景に芸術的な補完があります。測量、ナビゲーション、安全判断には使えません
- 初回データ量が大きく、低メモリ端末や遅い回線での使用感は未測定です
- パックを別originへ配信する構成、第三者の任意URLからのコース読込は未提供です
- 原Blender制作環境は同梱していません
- WebMCP関連機能は対応APIを検出する場合だけ登録され、対応ブラウザでの検証は未実施です

## 次に確認すること

WebGL 2対応の実環境で、[手動受入項目](MAINTENANCE.md#手動の受入確認)を実施し、ブラウザ名・版、OS、GPU、対象commit、結果と実スクリーンショットを記録します。未検証項目を「合格」に変えるのは、その観測ができてからです。
