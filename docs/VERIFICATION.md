# 検証記録と既知の制約

## 確認済み

- GitHub Pagesへ公開し、公開URLへ認証なしで到達
- 配布ファイルのSHA-256が公開commitの内容と一致することをCIで検査
- JavaScript構文、GLBヘッダ・長さ、内部パス・開発用URLの混入を検査
- コース契約26検査、10,016点の経路、209,834件の配置、車体から独立したパックの再配置・export後の再検査
- 読み込み中の描画context喪失を4段階へ注入した回帰テストと、初期化失敗時の案内・再読み込み動作テスト
- 手続き的な細部ノイズの画素サイズに応じた減衰、近接時の細部保持、Three.js材質へのshader差込の回帰テスト（GPU描画は含まない）
- コース補間・高さ・勾配・曲率が全周で有限値
- 無入力で停止、加速、制動、左右操舵、完走判定
- 自動走行の全周完走。v4基準データでは約25.03 kmを模擬約23分41秒、路肩接触0回
- 制作時の別検査でGLB復号、geometry結合、車体寸法、圧縮前後のbuffer一致を確認

最後の項目は現在の配布CIが自動再実行する範囲と同じではありません。CIが検査する内容は実際のテストスクリプトを参照してください。

## 分離後に追加した自動検査

コースsnapshotの版・32ファイルのSHA-256 pinと、取込の改変・危険なpath・車体上書き・symlink・欠損・版不整合・未承認更新の拒否を検査します。入力が不正なら書き込み前に拒否されることを小さなfixtureで確認します。配布checksumは全配信ファイルを過不足なく含むことも検査します。

## ブラウザ検証の限界

2026-10-04の公開確認に使ったクラウドChromiumはWebGL2がblocklist対象でした。通常のグラフィックアクセラレーション設定がONでも制約は継続しました。公開HTML/CSS/JavaScriptは読み込めますが、`WebGLRenderer` のcontext生成前に失敗し、ゲーム中の3D画面には到達していません。

そのため、以下は**未検証**です。

- 実ゲーム画面の材質・影・植生・全周の見た目
- 実ブラウザのキーボード・マルチタッチ操作の全経路
- デスクトップ・スマートフォン別のFPS、ロード時間、メモリ量
- 自動走行を実時間で最後まで表示した場合の安定性

WebGLを使えない場合の案内UIは用意しています。環境の保護機能を無効にして検証する方法は案内しません。

## 背景のちらつきへの対応

2026-10-04に実際の公開ゲームで背景がちらつく報告を受けました。地形の細部ノイズ（3.8セル/m）と一般材質の粒ノイズ（34セル/m）が、画素より細かくなっても平均化されず描かれていたため、画面上の微分で細部の大きさを調べ、解像できない部分だけ平均値へ滑らかに近づける処理を追加しています。近くの細部と地形の大きな色むらは保持します。

GLB全12ファイル・1,541メッシュプリミティブを復号した調査では、変換後の頂点・indexが完全一致する重複メッシュは見つかりませんでした。主地形437,358三角形にも完全重複や面積ゼロはありませんでした。ただし、これは部分的な重なりや深度精度に起因するちらつきを否定する検査ではありません。

数値試験では細部ノイズの減衰と既存操作の回帰を確認していますが、報告された実機症状との一致や修正後の実3D表示はまだ確認できていません。動く影、植生のLOD切替、遠方の近接した面の深度競合は残る調査候補です。実環境で、停止中と走行中の山・道路・沿道・木・影を分けて確認する必要があります。

## 既知の制約

- アーケード用の近似物理です。タイヤ・サスペンション・実車特性の厳密なシミュレーションではありません
- 道路形状や風景に芸術的な補完があります。測量、ナビゲーション、安全判断には使えません
- 初回データ量が大きく、低メモリ端末や遅い回線での使用感は未測定です
- パックを別originへ配信する構成、第三者の任意URLからのコース読込は未提供です
- 原Blender制作環境は同梱していません
- WebMCP関連機能は対応APIを検出する場合だけ登録され、対応ブラウザでの検証は未実施です

## 次に確認すること

WebGL 2対応の実環境で、[手動受入項目](MAINTENANCE.md#手動の受入確認)を実施し、ブラウザ名・版、OS、GPU、対象commit、結果と実スクリーンショットを記録します。未検証項目を「合格」に変えるのは、その観測ができてからです。
